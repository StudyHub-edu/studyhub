Management tools

Create student and teacher accounts, register institutions, and publish learning resources.

← Back to dashboard
01

Create a user

Use this form for students and teachers. Admin roles can only be assigned through the protected setup process.

02

Add a school or college

New institutions are added to the shared StudyHub directory and become selectable for accounts.

03

Upload learning content

Publish a JPG, PNG, or WebP image directly to the Notes library. Files are limited to 25 MB and are visible immediately.

Account and institution creation require SUPABASE_SERVICE_ROLE_KEY in backend/.env; restart the backend after adding it. Content uploads require the Supabase setup scripts admin_schema.sql and notes_schema.sql. Never put the service key in frontend code.
